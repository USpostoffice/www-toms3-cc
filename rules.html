rules

General rules for our gameservers.
Check SourceBans++ for Source bans.

Please note that some of these rules may not apply on certain servers.

To simplify this, each rule will have a game icon, which means that the rule does apply to the gameserver.

1. No cheating

Using external programs or in-game modifications to get any kind of advantage is strictly prohibited and will be penalized with a permanent ban. This does not apply to in-game tricks, as those are not considered cheating (a clear example is bunnyhopping).

2. No crashing

Intentionally crashing the server is prohibited and will be penalized with a permanent ban (for example, doing a lag machine on the minecraft server).

3. No lagging

Intentionally lagging the server is prohibited and will be penalized with a temporary ban.

4. No harassing

While we are not strict about toxicity, harassing is prohibited and will be penalized with a temporary ban. Please limit everything to what happens in-game.

4. No spamming or flooding

Spamming is prohibited and will be penalized with a permanent ban, and in the case of flooding, it's penalized with a temporary ban.
